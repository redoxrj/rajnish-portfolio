# Rajnish Kumar — Portfolio

A responsive React portfolio built with Vite, with project filters, accessible project dialogs, a career timeline, technical skill tabs, and email contact.

## Run locally

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

## Deploy to Vercel

Import the repository into Vercel. The included `vercel.json` selects Vite, runs `npm run build`, and serves `dist`. No environment variables or paid services are required.

## Edit the content

- Profile, links, project notes, experience, and skill groups: `src/main.jsx`
- Responsive design: `src/styles.css`
- Metadata: `index.html`
- Icons and social preview: `public/`

Professional project screens are original illustrative diagrams, not internal company screenshots. Company source code is not included. Performance figures reflect the owner's supplied experience; revenue figures are intentionally not published on this portfolio.

No phone number, CV file, analytics, tracking, or contact form backend is included. Contact links open the visitor's email application. The initials artwork can be replaced with a supplied portrait.
